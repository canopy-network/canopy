# CPLQ Operations

**In one sentence:** the five commands for moving, staking, and unlocking your CPLQ.

:::note Commands take a wallet nickname
Every `canoliqctl` command below takes the **nickname** of a wallet in your local keystore, not
a hex address. The one exception is a transfer's *destination*, which is a hex address.
:::

## CPLQ Transfer

Transfers liquid (already-vested) CPLQ between accounts.

```bash
canoliqctl cplq-transfer <from-nickname> <to-address-hex> <amount-uCPLQ>
```

Only vested CPLQ can be transferred. Vesting-locked CPLQ is not spendable.

## CPLQ Stake

Locks liquid CPLQ into a stake record, granting governance weight.

```bash
canoliqctl cplq-stake <nickname> <amount-uCPLQ> [--lock none|3m|6m|12m|24m]
```

**Effect**:
- Liquid CPLQ is debited
- `CPLQStake` record is created or aggregated
- `CanoliqGlobals.totalStakedCPLQ` is incremented
- `staked_at_height` is recorded for vote eligibility

:::tip Lock for more voting power
Pass `--lock` to commit the stake to a [vote-escrow lock tier](../tokenomics/vote-escrow.mdx) —
`3m`, `6m`, `12m`, or `24m` — multiplying voting weight up to 4× and boosting your share of
buyback rewards. Omit it (or pass `none`) to stake without a lock.

Locks only ever strengthen: you can raise a stake to a longer tier, never shorten it, and
locked stake cannot be unstaked until its lock ends.
:::

:::note Not the same as an OTC lock
This locks **CPLQ** for governance weight. The [OTC lock program](./otc-locks.mdx) locks
**cCNPY** for a one-off CPLQ reward. They are separate systems with separate durations.
:::

## CPLQ Unstake

Queues an unstake, returning CPLQ to liquid balance after the unbond window.

```bash
canoliqctl cplq-unstake <nickname> <amount-uCPLQ>
```

**Effect**:
- `CPLQStake.amount` is decremented
- An `UnstakingCPLQ` record is queued with `mature_height`
- `CanoliqGlobals.totalStakedCPLQ` is decremented immediately
- Voting weight drops immediately (prevents flash-unstake attacks)

## CPLQ Claim Unstake

Claims a matured unstake, returning CPLQ to liquid balance.

```bash
canoliqctl cplq-claim-unstake <nickname> <unstake-id>
```

## CPLQ Claim Vested

Unlocks newly-vested CPLQ across all of the caller's vesting schedules.

```bash
canoliqctl cplq-claim-vested <nickname>
```

Reads the `VestingIndex` to find all schedules, then computes unlocked amounts for each.
